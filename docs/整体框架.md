## 二、核心数据模型：招标主表（唯一数据源）

文件：`data/bidding/master_bids.json`（源）+ 每次运行导出 `.xlsx` 存档。

列（用户可见）：
`序号 | 项目名称 | 预计发布公告时间 | 发布时间 | 开标时间 | 投标单位 | 状态(已投/放弃/在投)`

内部附加字段：`命中关键词 | 来源 | 公告链接 | 去重键(项目名称+时间规范化) | 备注`

读写规则：
- ① 上传生成/重建主表初版（去重：项目名称规范化）。
- ② 每日抓取后按去重键合并：已存在跳过、新公告追加，自动补"发布时间/开标时间"。
- ③ 只读，筛选"开标时间 == 明日"。
- 投标单位、状态：不自动抓取，**由用户文字登记 → LLM/规则解析 → 写回主表**。

## 三、运行与调度架构

```
[GitHub 仓库 = 单一数据源（历史/主表/报告随运行 commit）]
  ├─ .github/workflows/*.yml   每日定时(09/16/17/18时) + workflow_dispatch 手动
  │     python 脚本 → 更新 data/ → git commit → Server酱推送个人微信
  ├─ jobs/                     5 个助手执行脚本（共享抓取/筛选/推送/LLM 库）
  ├─ data/                     主表、历史、分析报告产物
  └─ apps/web                  本机网页工作台
        Vue3 + Vite 暗黑科技 UI  ←HTTP→ 本地 FastAPI 后端
        （上传文件 / 手动触发 / 文字状态登记 / 产物查看与下载 / git pull 同步）
```

### 调度时间（北京 = UTC+8，GitHub cron 用 UTC）
| 任务 | 北京 | UTC |
|---|---|---|
| ③ 明日开标提醒 | 09:00 | 01:00 |
| ⑤ 国学自媒体 | 16:00 | 08:00 |
| ④ 银发康养自媒体 | 17:00 | 09:00 |
| ② 日招标筛选 | 18:00 | 10:00 |

已知局限与兜底：Actions 定时可能延迟数分钟、仓库长期无 push 可能暂停 → 工作台提供"手动运行"；后续可选本机 launchd 双保险。

## 四、关键设计决策

1. **关键词可配置**：投标词（EPC/PC/施工/风电/煤电/光伏/电缆）、自媒体词各自独立配置，工作台可编辑。
2. **去重**：① 项目名称规范化去重；② 对主表+历史去重；③ 开标时间=明日。
3. **爆款数据"尽力抓取+AI降级"**：每平台一个适配器（公开搜索页/热榜 JSON 尽力取 标题/作者/赞/评/藏/转/链接），抓不到则标记"降级"，由 DeepSeek 结合趋势生成候选并注明来源 → 保证每天有产出、不静默失败。
4. **状态文字登记**：工作台登记框输入如"XX风电项目 已投 中国电建"，解析后写入主表。
5. **推送格式**：Server酱不能发附件 → Markdown 表格推送，.xlsx/.json 存仓库可在工作台下载。
6. **密钥安全**：SCKEY / DeepSeek Key 只在本地 `.env`(gitignore) 与 GitHub Secrets。

## 十一、M2 落地记录（日招标项目筛选助手 · 已接入）

- 爬虫 `jobs/crawl_bidding.py`：国能e招招标公告频道分页抓取（选择器沿自 tender-monitor 验证值），按日期倒序并在越过目标日后停止；单条含 标题/链接/发布日期/md5
- 任务 `jobs/daily_bidding.py`（`python jobs/daily_bidding.py` 或后端 POST /api/jobs/daily/run 手动触发）：
  当日公告 → 关键词筛查（复用 parser.match_keywords，EPC 命中不重复计 PC）→ 详情页正则提取开标时间（尽力而为）→
  与主表按规范化项目名合并（同名补 发布时间/开标时间；否则追加行 source=国能e招）→ 写回 master_bids.json + 导出 xlsx/csv
  → 推送“新增/补全”表到个人微信（SCKEY 可选）→ 历史 md5 落 daily_history.json 防重复推送
- 调度：`.github/workflows/daily_bidding.yml`，cron `0 10 * * *`（北京 18:00）+ workflow_dispatch；轻量依赖 requirements-jobs.txt（requests/bs4/openpyxl）
- 界面：投标业务页 ② 日筛选面板（最近运行状态、立即运行、结果 chips、新增项链接列表）；③ 提醒模块新增“文字登记”（一行文：项目名 状态 投标单位 → 解析并填充后保存）
- 实测（2026-09-08）：当日公告 13 条 → 命中 2 条（EPC / 电缆）→ 详情开标时间成功提取（2026-10-08 09:00 / 2026-09-29 09:00）→ 主表 231 → 233 项
- 已知：站方列表按天分页、页容量可变；标题与月度计划名称不一致时按“新增行”处理（同名才合并）
